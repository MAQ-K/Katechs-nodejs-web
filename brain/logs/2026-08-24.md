Decisions worth knowing:
- **`getServerSideProps`, not static** — bare mode reads `?only=`, and static pages have no query
  server-side, which would flash the gallery before the specimen.
- **Viewport widths use an iframe** (`?only=<id>` bare mode). A CSS max-width wrapper does not re-fire media
  queries — it would show a narrow box still in its desktop layout, which is worse than not testing.
- **styled-jsx, no stylesheet.** Global CSS can only be imported from `_app.js` in the Pages Router; the lab
  must leave zero footprint on the real site.
- **Production gate**: `getServerSideProps` returns `notFound` when `NODE_ENV === "production"` + noindex meta.
- `utils/labData.js` reads `brain/` at `../../../brain` and **degrades to empty, never throws** — a fresh
  worktree must not 500 the lab.

## — Manager — T-023: interaction library + Lab tab consistency

**Lab consistency.** The Components tab didn't read like the others: cells were unbounded, so a full page
section and a 60px button demo sat in wildly different boxes and the page stopped looking like a gallery.
Both tabs now share one structure — `components/Lab/LabIndex.js` (sticky group-index chips with counts),
grouped sections with anchors and a blurb, and uniform cells capped at 520px with an **Expand** toggle
(`LabCell`). Motion was regrouped into Reveals & text · Hover & cursor · Scroll & parallax · 3D ·
Ambient & surfaces to match the Components tab's grouping.

**12 new primitives** in `components/Common/motion/`, all reduced-motion safe, SSR-safe, RTL-aware:
TextReveal · StaggerGrid · ScrollProgress · Parallax · ScrollScrub · Spotlight · Ripple · Cursor ·
CountUp · FlipCard · Orbit3D · Waves.

**Zero new dependencies** — a deliberate constraint, and most of what usually justifies an install turned
out to be reachable without one:
- `ScrollScrub` does motion.csv **#6** (pin + scrub) with `position: sticky` + framer scroll progress,
  no GSAP ScrollTrigger.
- `TextReveal` does **#9** without the paid SplitText plugin — and splits on **words, never characters**,
  because Arabic is cursive and per-character splitting breaks the joining forms.
- `StaggerGrid` replaces `back.out(1.4)` with a low-damping spring (**#8**).
- `Waves` is hand-rolled canvas, DPR capped at 2, one static frame under reduced motion so the section
  still looks designed.

Decisions worth keeping: `FlipCard` flips on hover **and** click/keyboard (hover-only is dead on a phone);
`Cursor` is scoped to its container and `pointer: fine` only; `Spotlight` drives a gradient from motion
values so mousemove never re-renders React; `CountUp` uses Latin digits + `tabular-nums` (every other
number on this RTL site is Latin, and tabular stops the row jittering); `ScrollProgress` fills from the
right in RTL.

**Nothing is applied to a page.** This is a library — T-012 and T-014f are where the Animator picks per
section. Noted in MANAGEMENT.md as the user asked.
