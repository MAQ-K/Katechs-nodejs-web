## How it's built — read before editing
- `scripts/build-content-new.js` converts each mockup → `data/content-new/<slug>.js` (GENERATED,
  don't hand-edit). **Re-run it when the team sends a new version.** It throws if the visible text
  of the output differs from the source by one character.
- Conversion: every class gets a `cn-` prefix and all CSS is scoped under `.cn-root` (Bootstrap
  has `.btn/.card/.h2/.lead`); mockup header/footer/WhatsApp dropped for the real Navbar, Footer,
  WhatsAppFab; internal `/web-design/…` links → `/web-design-new/…`; `[placeholder]` hrefs → `#`.
- `components/ContentNew/ContentPage.js` renders it: head meta + JSON-LD + canonical from the
  mockup, `noindex` (review copies), Cairo font, a `:where()` reset that undoes style.css element
  rules, hero padding for the fixed navbar, and the mockups' scripts ported (currency switch, tabs,
  reveal, before/after, video facade, email plan chooser).
- `?kw=1` on any of these URLs shows the team's keyword highlights + hover tips.
- Hub hero: the hands-and-sky photo (`/images/inspiration/webservices_page/placeholder.jpg`) per
  the team's only layout comment.
- Zero edits to `style.scss`, `Common/`, `Layouts/`, or any existing page.
