### Two findings that shaped the setup

**1. `components/HomeOne/` is orphaned.** Nothing imports it. The live homepage is composed from
`HomeTwo/` (MainBanner, ReviewsCounter), `Services/Services.js`, `PricingWebsite/**` and — for
eight of its twelve sections — **`components/Common/**`**. The **T-018 row in `MANAGEMENT.md`
names `components/HomeOne/**` as the homepage zone, which is wrong**; corrected in this run.

Real composition of `pages/index.js`, in order: MainBanner · ReviewsCounter · OurServices ·
MakeYourBusiness · PricingWebsite · MobileAppPromo · EcommercePlatforms · SeoShowcase ·
OurClientsGallery · Partner · TrustedCustomers · FaqHorizontal. OurProjects and Testimonials are
commented out.

**2. That `Common/**` dependency is why the rebuild is isolated.** Restyling the homepage in
place means restyling eight components shared with the rest of the site — the exact hazard the
"runs alone" scheduling rule covers for T-013/T-016. Building on a parallel route sidesteps it
entirely and stays reversible.

### Contract chosen for `components/HpNew/`

Same isolation contract as `components/Sections/`: one file per section, all styling via
`styled-jsx`, **zero writes to `styles/style.scss`** (12,733 lines, its own lock zone), inline
SVG icons (the `bxs-*` glyphs are missing from the bundled font anyway), props-with-defaults
now → `data/home-new/data.js` once copy settles, RTL-first logical properties
(`inset-inline`/`margin-inline`), Cairo headings, `prefers-reduced-motion` respected.

Consequence worth knowing: these sections do **not** inherit the `.ds-new-*` monochrome system
(G9/T-023). If the user wants the new homepage on that system, it gets ported into each section
file rather than imported.
