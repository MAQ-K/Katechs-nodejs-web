### Own mistake caught before shipping
First SCSS append attempt failed to compile — a code comment I wrote contained the literal
sequence `$dm-*/etc.`, which is a valid CSS comment-close (`*/`) sitting inside prose, so it
closed the comment early and everything after it read as broken CSS. Fixed the wording; worth
remembering when writing SCSS comments that mention `$var-*` shorthand next to another `$prefix`.
