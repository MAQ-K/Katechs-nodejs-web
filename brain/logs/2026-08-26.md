# 2026-08-26

## UI Implementer — Web Services page, Area 1 (the brief area)

`/services/` was a pure grey-box wireframe. Area 1 is now designed for real; everything below it
(النوع الأول/الثاني/الثالث) is still grey boxes, untouched.

**Section 1 — video hero (`.wsv-hero`)**
- Background: `/videos/katechs-services.mp4` (was staged in `public/videos/`, referenced nowhere until now).
- Shade over it: single layer `rgba(8,18,42,.45)` — black/dark-navy at 45%, as specified.
- Deliberately **not** 100vh: `min-height: clamp(460px, 62vh, 600px)`.
- 3 text-only slides (one fixed video), autoplay 6s, pauses on hover, 3 clickable dots bottom-right.
  Dots row uses `direction: ltr` on purpose — under the RTL root, `flex-end` would flip them left.
  Dots are anchored to the section, not the text, because `AnimatePresence mode="wait"` empties the
  text container mid-swap and they'd otherwise jump.
- Cross-fade via framer-motion; instant swap under `prefers-reduced-motion`.

**Section 2 — projects carousel (`.wsv-projects`)**
- Swiper 11, `dir="rtl"`, arrows only (no autoplay), loop, 3 → 2 → 1 slides at 1200 / 768.
- Arrows live in the section header, opposite the title. Refs bound via `onBeforeInit`.
- Uses the 6 existing images in `public/images/projects/`.

**Section 3 — service navigator (`.wsv-nav`)**
- 4 large cards (min-height 240px), 4 → 2 → 1 columns.
- Icon well + title + a "when you need this" line, phrased as «مناسب لك إذا…» per the content doc.
- Slow smooth hover as requested: 0.6s on transform / shadow / border, plus a cyan radial glow
  fading in. Transitions only, no keyframes, so no reduced-motion gate needed.

**Design system:** matched the newer service-page system (hosting/emails/app-dev/seo) — cyan `#1dd3f8`,
hairline `rgba(15,23,42,.08)`, 16px cards, Cairo 700–800 headings. Not the legacy Jumpx blocks.
Logical properties throughout, so `rtl.css` needed no additions.

**Open / for the user:**
- The 4 nav boxes ship with **placeholder** titles, briefs and hrefs — all in `data/services/data.js`.
- Project names/types in the same file are my best guess and likely need correcting.

**Verified:** sass compiles clean; `/services/` renders 200 on port 3001; all 3 sections in the SSR
markup; video + all 6 images return 200; dev log has no errors (only the pre-existing `_document.js`
viewport warning).
